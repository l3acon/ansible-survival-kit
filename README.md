# Ansible Survival Kit

Participant starter repository for **Ansible Island Adventure** — a gamified Capture the Flag competition built around Red Hat Ansible Automation Platform.

This repo is forked into each participant's Gitea account during environment provisioning. It contains the playbooks, roles, and encrypted files used across the CTF challenge categories.
This is the project used in Ansible Island Challenge to learn about Ansible Automation Platform in an exciting and fun way.
That is the Ansible Way.
